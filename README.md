# IYF Week 4: JavaScript Fundamentals

## About This Project
This repository contains my Week 4 JavaScript practice for the IYF Weekend Academy.

## What I Built
- JavaScript practice tasks covering variables, operators, functions, and control flow.
- A calculator that performs arithmetic operations.

- How to declare variables using `const` and `let`.
- How to use `===` for strict equality comparisons.
- How to write functions that return values.
- How to use array methods such as `map()`, `filter()`, `reduce()`, and `find()`.
- How to work with objects and JSON.
- How to test my code and track changes using Git and GitHub.
