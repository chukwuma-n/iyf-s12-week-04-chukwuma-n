# IYF Week 4: JavaScript Fundamentals

## About This Project

This repository contains my Week 4 JavaScript practice for the IYF Weekend Academy. It demonstrates my understanding of JavaScript fundamentals, functions, control flow, arrays, objects, and JSON.

## What I Built

- **JavaScript Fundamentals:** Variables, data types, operators, functions, and control flow.
- **Calculator:** Addition, subtraction, multiplication, division, remainder, and exponentiation, including division-by-zero handling.
- **Grade Tracker:** Calculates student averages and finds students using arrays and objects.
- **Array Practice:** Uses array methods to transform, filter, search, sort, and calculate data.
- **Objects and Arrays of Objects:** Creates objects and processes student records, including average grades and sorting.
- **JSON Practice:** Converts data to and from JSON, filters published posts, sorts by likes, and formats post summaries.
- **Daily Coding Challenges:**
  1. FizzBuzz
  2. Reverse a String
  3. Find the Largest Number
  4. Remove Duplicates
  5. Palindrome Checker

## What I Learned

- Declaring variables using `const` and `let`.
- Understanding data types and comparison and logical operators.
- Writing function declarations, function expressions, and arrow functions.
- Using conditional statements, `switch`, loops, and template literals.
- Working with array methods such as `map()`, `filter()`, `reduce()`, `find()`, and `forEach()`.
- Creating objects and arrays of objects.
- Converting data with `JSON.stringify()` and `JSON.parse()`.
- Handling edge cases such as division by zero and invalid operators.
- Testing JavaScript files with Node.js.
- Tracking project changes using Git and GitHub.

## How to Run

Open the project folder in Visual Studio Code. Open the terminal by clicking **Terminal → New Terminal**.

To run the main JavaScript exercises, type:

```bash
node main.js
```

To run the calculator, type:

```bash
node calculator.js
```

To run the grade tracker, type:

```bash
node grade-tracker.js
```

To run the FizzBuzz challenge, type:

```bash
node daily-challenges/fizzbuzz.js
```

Each command runs a different JavaScript file. Make sure you run the command from your project folder.
